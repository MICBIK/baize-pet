# 06 - 品牌与命名

> 状态：项目名已定 · 默认角色名待定 · 2026-10-26

## 1. 项目名：BaiZe（白泽）

**定名理由**：

1. **含义同构**：《山海经》中的神兽白泽"通天下万物之情"——知晓万物、有问必答、被奉为祥瑞。一只"见过你的每件事都记得、有问必答"的 AI 桌宠，与白泽的神话内核完全同构，且自带东方祥瑞的正面意象。
2. **创始人渊源**：与项目负责人姓氏（白）直接挂钩，品牌故事天然成立。
3. **语音交互彩蛋**：用户唤它"白泽"，本身就是一个有典故的称呼，传播时有故事可讲。

**英文/技术侧名称**：BaiZe（驼峰 Baize）。⚠️ 注意英文词 "baize" 本义为台面呢绒（台球桌布），无负面含义但需注意 SEO 时与该词区分——技术文档、npm scope、GitHub org 一律用 `baize` + 主题词（如 `baize-pet`、`baize-desktop`）保持可检索性。
