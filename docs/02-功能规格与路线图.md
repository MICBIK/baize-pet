# 02 - 功能规格与路线图

> 状态：v2（2026-10-26 按第二轮讨论修订：Electron、Mac 优先、引导式自配模型、本地语音、行为随机性、记忆导入导出）· 架构落地见 [03-架构设计](03-架构设计.md)，记忆系统细则见 [04-记忆系统设计](04-记忆系统设计.md)

## 1. 六大功能支柱

### 1.1 形象与角色包

- 默认角色**自设计**（版权自有、人设与产品逻辑自洽）。
- **人设预设 + 自定义**：出厂内置 3-4 套预设人格种子（治愈 / 傲娇 / 捣蛋 / 知性方向各一），用户可基于预设调整参数形成自己的性格；人设参数全部外置（行为打分权重、情绪衰减曲线等），自定义有真实效果而非改名。
- **角色包** = manifest（外观 + 人设参数 + 动作库 + 音色配置）打包分发，平台与角色解耦。
- 社区可自打包任意形象自用（包括鲸鱼娘等同人形象——我们不分发，责任隔离）。
- 素材链支持 AI 生成：提示词 → 绿幕视频 → 抠像 → VP9-Alpha webm（dsh-pet 已验证该流程可复现）。

### 1.2 记忆与遗忘（核心壁垒）

四层记忆（工作 / 语义 / 情景 / 程序性）+ 艾宾浩斯式遗忘退化 + 睡眠时段后台整理。完整设计见 [04-记忆系统设计](04-记忆系统设计.md)。产品层可见特性：

- 对话式 onboarding：第一次见面问名字、起名——**起名仪式即第一条情景记忆**。
- 自我画像渐进完善：每次对话后台抽取"关于主人 / 关于自己"的事实写入语义记忆。
- **画像页可视化**："它理解中的我 / 它理解中的自己"——天然传播素材。
- 回忆相册：用户可翻阅它的记忆、pin 住重要事件（永不遗忘）、看它"想不起来"的印象碎片。
- **记忆导入 / 导出（第一阶段必做）**：一键导出完整记忆（SQLite 文件 + JSON），在新电脑一键导入，换机不"失忆"。

### 1.3 面向普通人

- **引导式自配模型（第一阶段）**：不内置默认模型、不提供免费额度。首次启动由宠物以引导动画带用户完成配置：选厂商 → 跳转注册 / 获取 key → 粘贴 → 测试连通。未来再考虑：厂商愿意提供的免费模型，或内置一个小型本地模型作为默认。
- 模型配置 = **接口聚合，想用哪家用哪家**：OpenAI 兼容族（GPT / DeepSeek / GLM / Kimi / MiniMax / 小米 MiMo / 本地 Ollama）+ Anthropic 协议适配器（Claude）；贴各自平台的 key 即用，无独占默认供应商。
- 语音、记忆等高级能力做成可选"增强包"下载，保住首包轻量。
- 工程事项：第一阶段自签名 / ad-hoc 签名（引导用户在系统设置中放行）；更新采用"检测新版本 → 提示 → 打开下载页"，有开发者证书后再做静默自动更新；崩溃日志只存本地；token 成本由用户在设置中自行设定上限。

### 1.4 能干事（执行层三档）

| 档 | 能力 | 技术路径 | 风险 |
|---|---|---|---|
| 1（MVP 必做） | 状态感知 + 提醒：agent hooks、终端空闲、git 事件、久坐 → 动画 + 通知 + 语音播报 | 纯监听，只读 | 零 |
| 2（V2） | 代传话：替用户向 agent 工具转述指令并发送 | 官方通道优先（hooks / stdin / IPC / tmux / ConPTY 注入） | 低 |
| 3（V3，插件化） | UI 代操作：跨应用点击、表单 | Windows UIA / macOS 辅助功能 API / computer-use 模型 | 高（见下） |

档 3 硬性要求：操作白名单 + 敏感动作二次确认（"我要替你发：xxx，确定吗？"）+ 操作全程可回放审计 + 引导用户开启系统授权。**做成可选插件而非核心**。

### 1.5 语音

- **全本地、零云费**：VAD（silero）→ 本地 ASR（sherpa-onnx + SenseVoice-Small 等）→ LLM 流式 → 分句本地 TTS（sherpa-onnx + MeloTTS / Kokoro 等开源中文模型）。语音模型作为"语音包"首次使用时下载，主包保持轻量。
- **触发方式**：默认全局监听（麦克风常开 + 本地 VAD + 唤醒词"白泽"/角色名，命中后才进入识别）；对权限有顾虑的用户可在设置中改为**快捷键触发**。
- **Barge-in 必做**：用户开口立即停 TTS + 截断 LLM 流——自然感的最大来源。依赖回声消除（AEC），避免宠物听到自己的声音误触发。
- 目标首响 < 1 秒（受用户所选模型影响）。说话时口型同步。
- 音色只使用许可明确、允许再分发的开源音色；**不提供声音克隆功能**，后续有需求再评估（见 [05 §4](05-许可证与合规.md)）。
- 麦克风 / 输入监控等系统权限的首次请求放进引导动画，话术友好化。

### 1.6 行为与情绪（灵魂感来源）

- **行为系统**：动作库（原子动作 + 复合剧本）+ 效用选择器 + 打断优先级（用户拖拽 > 对话 > 自发行为）。
- **规则 + 随机 + LLM，同一场景不重样**：
  1. 规则识别场景并圈出候选（如"深夜 + 主人还在敲代码"对应 5-8 个候选动作）；
  2. 候选按情绪 / 时段 / 近期事件打分后**按分数加权随机抽取**（而非固定选最高分），配合冷却与重复惩罚，避免连续重复；
  3. 台词来自**台词池**：空闲时由 LLM 结合当前情绪与近期记忆为各场景批量生成十余句缓存，触发时随机抽取；池子用完或过期后重新生成；
  4. 对话、久别重逢等低频节点才实时调用 LLM。
  效果：同一场景每次的动作与台词都不同，且随心情和记忆变化；自发行为仍是毫秒级、零等待。
- **情绪系统**：情绪值向量（开心 / 无聊 / 生气 / 思念）随交互频率衰减累加。几天不互动 → 生气剧本，但分级、有台阶（摸两下哄好，最重"傲娇式冷战"且有自动恢复）。
- **桌面图标互动**（Windows 特性功能）：桌面是 ListView 窗口，可读图标坐标，宠物可"跑过去扒拉"（视觉假象）。macOS 无公开 API，降级为 Dock / 菜单栏旁互动。

## 2. 全渠道接入

原则：**同一颗大脑**（桌面端与 bot 共享记忆 / 人设 / 情绪状态，跨端连续）；**适配器架构**（统一通道接口：收文本/语音/图片，发文本/语音/图片）；**本地优先**（bot 网关跑在用户桌宠进程内，记忆不出门）；**身份归一**（桌宠端配对码绑定多渠道身份）。

| 平台 | 接入方式 | 语音格式 | 顺序 |
|---|---|---|---|
| Telegram | 官方 Bot API（免费、零审核） | 语音条 OGG/Opus | 优先（接入最简单，面向海外 / 开发者） |
| 飞书 | 官方开放平台自建应用（个人可建、免费），使用长连接模式，无需公网服务器 | 文件/音频消息 | 优先（国内用户首选） |
| QQ | 官方 bot 平台受限；社区走 NapCat/LLOneBot（OneBot 协议） | Silk | 只做 OneBot 适配，连接由用户提供 |
| 微信 | **仅企业微信自建应用**；个人号逆向有封号与违法风险 | Silk/AMR | 官方项目只做企微，README 明确声明 |

接入原则：**哪个方便接、兼容性好就先接哪个**，不要求每个渠道都做到完美；企业微信自建应用需要可信域名 / IP 回调，与"网关跑在本机"冲突较大，优先级最低。

语音往返复用 1.5 管线 + ffmpeg 按平台转码（TG→Opus、QQ/微信→Silk、飞书→文件消息）。

**安全模型**：远程通道默认只开"聊天 + 状态播报"权限；远程批准 agent 操作 / 触发执行层必须是显式开关 + 二次确认。

## 3. 路线图

> 长期项目，按阶段推进、不设固定工期。平台顺序：**先 macOS，再 Windows**（Windows 一定会做）。

### 阶段一（MVP）
- 角色包架构 + 默认角色（3-5 个动画组：待机/点击/拖拽/兴奋/生气）
- 规则 + 加权随机的行为系统 + 情绪系统基础版（台词池可先用预置台词，LLM 生成在阶段二补上）
- 文字对话 + 起名仪式 onboarding + 模型配置引导动画 + 画像页 v1
- 分层记忆基础版（语义 + 情景 + 标签 + 简单检索）+ **记忆导入 / 导出**
- 系统通知 / 久坐提醒 / 档 1 状态感知
- Electron + TypeScript 骨架：**macOS 优先**；GitHub Actions 自动构建与发布（自签名）
- 冷启动渠道：GitHub + Gitee 镜像（国内访问）+ linux.do（开发者口碑）+ 小红书 / 抖音（赛博宠物内容营销）双轨并行

### 阶段二
- **Windows 版**（同一套代码，补齐平台差异）
- 本地语音全管线（全局监听 + 唤醒词 / 快捷键触发、barge-in、口型）
- LLM 台词池
- Telegram + 飞书渠道；agent hooks 联动 + 档 2 代传话
- 记忆睡眠整理 + 遗忘退化 + 回忆相册
- 角色包社区规范 v1 + 素材链工具

### 阶段三
- 本地 LLM（Ollama / llama.cpp；Mac 可接 Apple 端侧模型），作为未来"内置默认模型"的候选
- Windows 桌面图标互动、档 3 代操作插件
- 性格演化可视化、QQ / 企微渠道
- 商店上架（Microsoft Store 优先）
