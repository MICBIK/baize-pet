## 2. 关键趋势洞察

1. **怀旧 → AI 伴生换挡**：Reddit（r/CozyGamers）讨论桌宠复兴 + GitHub 2025-2026 新增项目几乎都带 AI 联动。新爆款公式 = **角色魅力 × 情绪价值 × 与真实工作/系统状态联动**。
2. **"赛博装修"经济**：量子位报道 DeepSeek Harness 插件 700+ 个，桌宠/小游戏/怀旧 UI 类是爆火主力——用户既需要效率工具，也乐于为情绪价值装修自己的数字空间。
3. **Agent 事件源是新增基础设施**：Claude Code / Codex 等 agent hooks 已是标准能力，clawd-on-desk 用 6.5k 星验证了"监控编程 Agent 的桌宠"是真实需求。同期还有 TokenTracker（2.1k，token 成本追踪）等伴生工具。
4. **AI 生成素材链已被验证**：dsh-pet 的"提示词 → 绿幕视频 → 透明动画"流程让个人产出角色动画的成本大幅下降——这直接支撑我们自设计角色的决策。

## 3. dsh-pet 弱点剖析（用户最初的不满，社区有共识）

- **交互是"点播"不是"互动"**：动画靠右键菜单点播 + 随机播放，宠物无自主决策。
- **生态绑架**：独立运行模式下对话、碎碎念、余额展示、系统通知全部不可用（残血版）。
- **无语音、无养成、无长期关系**：记忆有持久化但无性格演化，一周即腻。
- 工程层：Safari 不支持透明 webm；与 DSH 主程序可能互踩 Electron 缓存。

## 5. 形象版权考据（支撑"自设计角色"决策）

- 鲸鱼娘（蓝色大肥鱼）源自画师"上善无形"2025 年 6 月的 AI 原创 OC"溟月"，后被社区二创与 DeepSeek 挂钩；**DeepSeek 官方从未收编，版权归属悬置**。
- 相关表情包仓库只能声明"角色形象与原始画作版权归原作者"。
- 2026 年 9-10 月爆发"鲸鱼娘派 vs 男版 D 老师"正统之争，画师被逼隐藏作品——此时蹭热度 = 版权雷区 + 舆论雷区双踩。
- 结论：**自设计默认角色 + 角色包架构**。社区想养鲸鱼娘可自行打包自用（我们不分发，责任隔离）。
