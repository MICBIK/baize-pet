# Open Questions（待裁决 / 已按保守方案处理）

按 [07-工程骨架方案 §5](07-工程骨架方案.md) 的约定，实现中发现文档矛盾、无法实现或需要产品判断的地方记录在此，先按最保守的方案实现，不擅自更改产品决策。

## 2026-10-26（M0）

1. **Node 版本：文档要求 22 LTS，本机为 24**
   - 矛盾：[07 §2](07-工程骨架方案.md) 规定 Node.js 22 LTS；执行环境安装的是 Node 24。
   - 处理：`engines` 设为 `>=22.12`（22 LTS 与 24 均满足），CI 统一使用 Node 22（`ci.yml` / `release.yml` 的 `setup-node`）。发布产物由 CI（Node 22）构建，不受本机版本影响。此为环境差异记录，不算选型变更。

2. **自动化安全扫描的"拒绝本地地址"约束与 Ollama 预置配置的冲突（影响 M4）**
   - 矛盾：生成前安全约束要求出网请求拒绝 localhost / 私有地址；[07 §4 M4](07-工程骨架方案.md) 与 [02 §1.3](02-功能规格与路线图.md) 明确预置 Ollama（`http://localhost:11434`）作为 OpenAI 兼容档位。
   - 处理：出网白名单按 07 执行——只允许（a）用户在设置中显式配置的模型服务端点（含 Ollama 本地端点，用户配置即授权）与（b）GitHub Releases 公开 API 的更新检查。模型端点校验仅限制协议为 http/https；"拒绝私有地址"的强制校验只用于非用户配置场景（当前代码中没有此类请求）。留待负责人裁决是否有必要对本地端点做额外确认弹窗。

## 2026-10-26（M3）

3. **工作记忆不进入导出文件**
   - 说明：[04 §1](04-记忆系统设计.md) 将工作记忆定义为"固定 N 轮的当前对话窗口（内存）"。导出格式（`baize-memory-export` v1）包含语义 / 情景 / 程序性三张表，不含工作记忆——它是易失的对话上下文而非长期记忆。若产品希望导出文件也携带"最后一段对话"，需要调整导出规范（会连带影响导入校验），留待负责人确认。

4. **向量检索（sqlite-vec）本轮未接入**
   - 说明：07 §4 M3 明确"向量检索先留接口，embedding 模型下一轮接入"，因此 `episodic_events.embedding` 列已预留（BLOB，当前恒为 NULL），`recall()` 的 relevance 分量目前由标签命中率充当，公式 α·recency + β·importance + γ·relevance 的结构与权重（默认 0.3/0.4/0.3）已外置。sqlite-vec 依赖留到接入 embedding 时再引入（减少本期 native 依赖面）。

## 2026-10-26（M4）

5. **Anthropic 预设的默认模型名**
   - 说明：向导默认值已按 2026-10 的公开信息更新为 `claude-sonnet-5-5`（Sonnet 5.5，2026-09-28 发布），但 Anthropic 未在其文档中确认该 API 字符串的准确写法（也可能是带日期后缀的别名）。产品侧应确认向导中 Anthropic 档默认推荐哪个模型（以及是否随时间更新），模型名可由用户在向导中覆盖。

6. **"点击宠物或快捷键打开输入框"中快捷键的实现方式**
   - 说明：本轮实现了"点击宠物打开独立聊天窗口"；"快捷键"未做全局快捷键（`globalShortcut` 会占用系统级组合键，存在与用户已有快捷键冲突的产品判断），保守起见留给下一轮（可做成设置项，默认关闭）。07 原文为"点击宠物**或**快捷键"，单一路径已满足验收。

7. **对话历史仅保留本次会话**
   - 说明：工作记忆（固定 12 轮）只在内存中，重启后聊天窗口为空（历史对话已按摘要写入情景记忆，可被 recall 检索）。若产品希望重启后聊天窗口显示上一段对话，需要从情景记忆重建视图，留待确认。

8. **renderer 侧 `window.baize` 部分方法类型推断为 any**
   - 说明：root tsconfig（moduleResolution: bundler）下，`baize.d.ts` 经 `typeof api` 引入的 preload API 中，部分新增方法在 renderer 文件里推断为 any（已用显式参数类型标注绕过，不影响运行时）。待后续统一 renderer/preload 的类型组织方式（如独立 `env.d.ts` 直接引用 shared 类型）。
