# BaiZe 白泽

> 一只有灵魂的 AI 桌宠 —— 桌宠形态的个人 AI Agent。

BaiZe（白泽）是一只住在桌面上的宠物，但不是"会动的贴纸"：它有分层的长期记忆，会遗忘也会回忆；有情绪和自主行为，会捣蛋也会生气；能说话能听话，能盯着你的任务并在关键时刻出声；所有记忆数据只存在你的电脑里。

取名自《山海经》中通晓天下万物的神兽"白泽"——它见过你的每一件事，都记得。

## 一图看懂差异化

现有竞品的交集是空的：

- BongoCat：交互好，但没有 AI 灵魂
- clawd-on-desk：Agent 联动好，但像素风、不能聊
- Open-LLM-VTuber：AI 全家桶，但没有"住在桌面上"的轻量感
- dsh-pet：动画多，但本质是"点播式贴纸"

BaiZe 要做的就是这个交集：**可爱的壳 + 有记忆、有性格、能干事的芯**。
